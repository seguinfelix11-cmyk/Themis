# Themis — Site Web Professionnel

**Themis** — *LSAT prep and application review | Préparation LSAT et révision dossier d'admission.*

Site web professionnel bilingue (français / anglais) dédié à la préparation au LSAT, à la révision de CV et de personal statement pour les candidat·e·s aux études de droit.

## Sections

- **Accueil** — Page d'accueil avec présentation
- **À propos** — Présentation de Themis et de l'accompagnement proposé
- **Services** — Préparation LSAT, Personal Statement, Révision de CV
- **Tarifs** — Grille tarifaire des services
- **Rendez-vous** — Prise de rendez-vous via Calendly

## Tarifs

| Service | Tarif |

## Technologies

- HTML5
- CSS3 (design responsive)
- JavaScript (vanilla) — bascule de langue FR/EN
- Intégration Calendly

## Démarrage

Ouvrez simplement `index.html` dans votre navigateur, ou utilisez un serveur local :

```bash
# Avec Python
python3 -m http.server 8000

# Avec Node.js
npx serve .
```

## Personnalisation

- Remplacez le lien Calendly placeholder (`CALENDLY_PLACEHOLDER` dans `index.html`) par votre lien Calendly réel, p. ex. `https://calendly.com/votre-nom/consultation`
- Mettez à jour les informations de contact si nécessaire
- Ajoutez vos propres images dans le dossier `images/`
- Modifiez les tarifs dans la section Tarifs (`index.html`) et les traductions dans `script.js`
