# Cabinet Avocate - Site Web Professionnel

Site web professionnel pour un cabinet d'avocate spécialisé dans les services LSAT, CV et Personal Statement.

## Sections

- **Accueil** — Page d'accueil avec présentation
- **À propos** — Présentation du cabinet et de l'avocate
- **Services** — LSAT, CV, Personal Statement
- **Tarifs** — Grille tarifaire des services
- **Rendez-vous** — Prise de rendez-vous via Calendly

## Technologies

- HTML5
- CSS3 (design responsive)
- JavaScript (vanilla)
- Intégration Calendly

## Démarrage

Ouvrez simplement `index.html` dans votre navigateur, ou utilisez un serveur local :

```bash
# Avec Python
python3 -m http.server 8000

# Avec Node.js
npx serve .
```

## Personnalisation

- Remplacez le lien Calendly placeholder dans `index.html` par votre lien Calendly réel
- Mettez à jour les informations du cabinet (nom, adresse, téléphone, email)
- Ajoutez vos propres images dans le dossier `images/`
- Modifiez les tarifs dans la section Tarifs
